Marrow — media types & visual vocabulary

Everything Marrow can produce, the two rendering backends it draws with, the visual language inside a diagram, and the icon libraries that feed it. This page is self-contained — like every Marrow output, it makes zero network requests.

1 · Output media — 6 formats

What a topology YAML can become.

Single-file HTMLbuild

One self-contained interactive page — icons, styles, runtime all inlined. Opens offline from a double-click. Used for networks up to ~150 devices.

Multi-page sitebuild

A folder: overview + zone pages + device-360 pages + inventory + cross-page search. Auto-chosen above ~150 devices or 5 zones. Still fully offline.

PNGsnapshot · ⌘K export

Raster image — the agent’s “eyes” via marrow snapshot, and a 2× export from the viewer’s command center.

SVG⌘K export

A standalone vector document with styles inlined — infinite zoom, editable in Illustrator/Figma. Available on SVG-tier pages.

Live previewserve

The dev server renders exactly what build ships, page-by-page, with memoized rebuilds and targeted hot reload on YAML edits.

PrintCtrl P

A print stylesheet strips all chrome and flattens the stage onto white paper.

2 · Render tiers — 2 backends, one look

Every page picks a backend by rendered-node count; the interaction layer and visual style are identical on both.

TierBackendBudgetWhy
HeroServer-rendered SVG DOM≤ 250 nodes / pageCrisp at any zoom, CSS-animatable, exportable as vector, accessible via the DOM.
ScaleCanvas engine250 – 1,200 nodes / pageOne draw surface stays smooth where thousands of DOM elements would not. Above 1,200 the planner refuses and splits into zone pages instead.

3 · Device visuals

A node is a chip (rounded card) carrying a vendor icon, a status LED, and a label. State changes the ring.

4 · Link visuals

Edges encode speed as thickness, status as stroke style, and traffic as motion. 7 declared kinds (copper, fiber, dac, wireless, virtual, wan, serial) and 9 speeds (10M → 400G).

5 · Grouping visuals

Zones are tinted panels with tracked-caps titles; they nest, collapse, and become clickable pages in site mode.

8 · Ambience

Watermark

Giant low-contrast topology title inside the stage — orients screenshots and exports.

Backdrop branding

Author-declared brand line (top) and confidentiality note (bottom) in the page margin, via backdrop: in YAML.

Minimap

Corner overview with zone tints and status dots; drag to fly the camera.

Entrance choreography

Zones fade, nodes rise, edges draw in — skipped on reload, deep links, and reduced-motion.

Focus dimming

Hover/selection dims everything outside the device’s neighborhood.

LOD bands

Far zoom hides labels; near zoom reveals port chips — density adapts to the camera.

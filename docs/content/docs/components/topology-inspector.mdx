The **Topology Inspector** is a card-based telemetry panel for network engineering. It provides 5 segmented tabs: **Overview**, **Interfaces**, **Neighbors**, **Fields**, and copyable **CLI Configurations** (Cisco IOS-XE, Arista EOS, PAN-OS, Junos).


Or directly from the GitHub repository:


## Features

- **5 Segmented Tabs**:
  - `Overview`: Hardware model, OS version, management IP, serial number, role, uptime.
  - `Interfaces`: Full table of device ports with link mode (`routed`, `trunk`, `peering`, `tunnel`), speed, VLAN, and live status indicator.
  - `Neighbors`: LLDP and CDP adjacent peer discovery table.
  - `Fields`: Custom metadata tags, BGP autonomous system numbers (ASNs), circuit IDs.
  - `Config`: Formatted vendor CLI configuration stanza with 1-click clipboard copy.
- **Auto-Syncing Selection**: Automatically updates whenever a node or link is selected in the canvas.
- **Translucent Backdrop**: Soft blur background with border halo that matches your theme.

```tsx
      </aside>
    </TopologyProvider>
  );

```

## Props

The component reads from the shared `useTopologyShell()` context, but you can also pass custom container classes:

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `className` | `string` | `undefined` | Optional Tailwind classes applied to the root card. |

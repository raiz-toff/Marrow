---

The **Cable & Link Badge** (`<CableBadge />`) is a compact visual indicator for physical and logical network links. It displays cable line styles (solid, dashed, double-rail trunk), operational status colors, port speeds, and optional packet animation pulses.

## Features

- **Link Modes**: Styled representations for `trunk`, `access`, `routed`, `tunnel`, and `peering`.
- **Traffic Pulse Animation**: Optional animated packet ping to indicate active flow telemetry.
- **Speed Chip**: Integrated mono chip for line rates (`1G`, `10G`, `25G`, `40G`, `100G`, `400G`).

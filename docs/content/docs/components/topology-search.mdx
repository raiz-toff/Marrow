## Features

- **Keyboard First**: Press `Ctrl+K`, `Cmd+K`, or `/` anywhere in the app to open.
- **Unified Multi-Category Filter**:
  - **Devices**: Matches hostnames, models, serial numbers, and roles.
  - **IP Addresses**: Searches management IPs, interface subnets, and loopbacks.
  - **Security Zones**: Filters down to specific zones.
  - **Links**: Finds cables and trunks by endpoint names.
- **Fast Camera Teleportation**: Selecting any search result automatically focuses and centers the canvas camera on that device while opening its inspector drawer.

## Usage

```tsx
import { TopologyProvider, TopologySearch } from "@/components/marrow/topology-search";

export default function Layout() {
  return (
    <TopologyProvider>
      {/* TopologySearch stays hidden until Ctrl+K is pressed */}
      <TopologySearch />
    </TopologyProvider>
  );
}
```

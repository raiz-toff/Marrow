---
title: Device Link & Micro-Topology
description: Compact, inline network link component for rendering peer-to-peer device interconnections without canvas or iframe overhead.
---

The **Device Link** (`<DeviceLink />`) component renders clean, lightweight peer-to-peer network connections directly in your documentation, dashboards, or runbooks without loading an entire iframe or SVG canvas.

It supports device role icons, interface port chips, IP badges, operational status LEDs, cable line styles (trunk, routed, tunnel, peering), and traffic flow animations.

---

## Props Reference

### Device Properties (`from` / `to`)

| Property | Type | Description |
| :--- | :--- | :--- |
| `name` | `string` | Device hostname or display label. |
| `role` | `string` | Subtitle role or model label (e.g. `Catalyst 9500`, `router`, `switch`). |
| `icon` | `ReactNode \| string` | Vendor SVG URL (`/icons/...`), raw SVG markup (`<svg...`), or custom React element. |
| `port` | `string` | Interface identifier (e.g. `Eth1/48`, `Gi0/1`, `eth0`). |
| `ip` | `string` | IP address badge displayed beside the device name. |
| `status` | `'up' \| 'degraded' \| 'down' \| 'planned'` | Status LED dot indicator. |

### Cable Properties (`cable`)

| Property | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `mode` | `'routed' \| 'trunk' \| 'tunnel' \| 'peering' \| 'access'` | `'routed'` | Visual line wire style (solid, double-line, dashed, dotted). |
| `speed` | `string` | `'10G'` | Line rate badge label (e.g. `1G`, `10G`, `100G`). |
| `label` | `string` | - | Optional custom overlay text (e.g. `IPsec Tunnel`, `VLAN 20`). |
| `status` | `'up' \| 'degraded' \| 'down' \| 'planned'` | `'up'` | Operational color applied to the cable wire. |
| `animated` | `boolean` | `false` | Enables live packet flow pulse indicator. |

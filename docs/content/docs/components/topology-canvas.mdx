The **Marrow Diagram Embed** (`<MarrowEmbed />`) shows a diagram built by
`marrow build` inside an `<iframe>`. The diagram brings its own layout, icons,
inspector and runtime, so nothing is re-rendered in React and nothing collides
with your CSS.

## Installation

```bash
npx shadcn@latest add https://marrowdiagram.vercel.app/r/topology-canvas.json
```

This copies `components/marrow/topology-canvas.tsx` and
`components/marrow/topology-types.ts` into your project and installs
`lucide-react`, `clsx` and `tailwind-merge`. The component is styled with the
standard shadcn tokens (`bg-card`, `border-border`, `text-muted-foreground`,
`bg-accent`, …), so it follows your theme. Nothing is published to npm: you own
the copied source.

Inside a Marrow checkout, `npm run marrow -- add topology-canvas --out <dir>`
copies the same files.

## Usage

### A built diagram (`src`)

Serve the output of `marrow build` from your `public/` folder or any static host:

```tsx
import { MarrowEmbed } from "@/components/marrow/topology-canvas";

export function DatacenterTopology() {
  return (
    <MarrowEmbed
      src="/diagrams/datacenter.html"
      title="Datacenter fabric"
      aspectRatio="16 / 9"
    />
  );
}
```

### Compiled markup (`html`)

When the HTML comes from an API or a build step as a string, pass it as `html`;
it is rendered through `srcdoc`. The flags are written onto the document's
`<html>` element, since a srcdoc document has no URL. It runs under **your
page's Content Security Policy** — allow its inline script and styles, and
`blob:` images for PNG export — see [Embedding: compiled markup](/docs/guides/embedding#compiled-markup-instead-of-a-url-html).

```tsx
export function GeneratedTopology({ compiledHtml }: { compiledHtml: string }) {
  return <MarrowEmbed html={compiledHtml} title="Generated topology" height={600} />;
}
```

### Presets

Switch between several diagrams in one frame. Without `src`, the first preset is shown:

```tsx
export function MultiSiteDiagram() {
  return (
    <MarrowEmbed
      presets={[
        { label: "Campus core", src: "/diagrams/campus.html" },
        { label: "Branches", src: "/diagrams/branches.html" },
        { label: "WAN", src: "/diagrams/wan.html" },
      ]}
    />
  );
}
```

### Load errors

The diagram posts `marrow:ready` once it has booted; that is the success signal.
If it does not arrive within `loadTimeout` (8 s by default) — a 404, a blocked
frame, a page that is not a Marrow diagram — `onError` fires and `fallback` is
shown over the frame:

```tsx
<MarrowEmbed
  src="/diagrams/wan.html"
  onError={(err) => report(err)}
  fallback={<p className="p-6 text-sm">The WAN diagram is unavailable.</p>}
/>
```

### Talking to the diagram (`ref`)

The `ref` is the `<iframe>`. When the diagram is same-origin (same host, or `html`),
its [`window.marrow` API](/docs/guides/embedding#javascript-client-api-windowmarrow)
is reachable through it:

```tsx
const frame = useRef<HTMLIFrameElement>(null);

<MarrowEmbed
  ref={frame}
  src="/diagrams/campus.html"
  onReady={() => frame.current?.contentWindow?.marrow?.selectDevice("core-sw-01")}
/>;
```

Cross-origin, `contentWindow.marrow` is not accessible; use URL parameters
(`src="/x.html#d=core-sw-01"`) instead.

## Behavior

- **Flags before first paint.** `chrome`, `inspector`, `minimap` and the theme are
  added to the frame URL's hash (`#chrome=minimal;theme=dark`), which the
  diagram's pre-boot script applies before it paints. Your own hash pairs
  (`#d=<device>`) are kept.
- **Theme.** With `theme="auto"` the host theme is read when the frame first
  loads — a `dark` or `light` class, or `data-theme`, on `<html>`; otherwise
  `prefers-color-scheme` — and put on the URL, so the frame never flashes the
  wrong theme. Later changes are sent with `postMessage` and do not reload it.
- **Client-side load.** The frame URL is set after hydration, so the ready
  message can't be missed during server rendering.
- **Several embeds.** Each instance only reacts to messages from its own frame.
- **Fullscreen** uses the Fullscreen API, or a fixed full-viewport overlay where
  it is unavailable (iOS Safari); Escape exits the overlay.
- **Sizing.** 600 px tall by default, with a 320 px floor. Both are Tailwind
  classes, so `className="h-full min-h-0"` overrides them; `height`, `aspectRatio`
  and `minHeight` set inline styles.

## Props

One source is required — `src`, `html` or `presets`. TypeScript enforces it,
and `src` and `html` are mutually exclusive.

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `src` | `string` | — | URL of a diagram built by `marrow build`. |
| `html` | `string` | — | Compiled HTML, rendered through `srcdoc`. |
| `presets` | `{ label: string; src: string }[]` | — | Diagrams to switch between; the first is shown when `src` is absent. |
| `title` | `string` | `"Marrow Network Diagram"` | Accessible title of the iframe. |
| `chrome` | `'minimal' \| 'full'` | `'minimal'` | `minimal` hides the command bar, breadcrumbs, sidebar, backdrop, watermark and minimap. |
| `inspector` | `'on' \| 'off'` | `'on'` | Device and link inspector drawer. |
| `minimap` | `'on' \| 'off'` | `'on'` | Minimap overlay (only visible with `chrome="full"`). |
| `theme` | `'auto' \| 'dark' \| 'light'` | `'auto'` | `auto` follows the host page. |
| `height` | `string \| number` | — | Fixed height (numbers are px). Without it, a `h-[600px]` class applies. |
| `aspectRatio` | `string` | — | CSS `aspect-ratio`, e.g. `"16 / 9"`. Replaces the default height. |
| `minHeight` | `string \| number` | — | Minimum height. Without it, a `min-h-[320px]` class applies. |
| `floatingActions` | `boolean` | `true` | Preset switcher, open-standalone link and fullscreen button. |
| `loadTimeout` | `number` | `8000` | Milliseconds to wait for `marrow:ready` before `onError`. |
| `onReady` | `() => void` | — | The diagram posted `marrow:ready`. |
| `onError` | `(error: Error) => void` | — | No `marrow:ready` within `loadTimeout`. |
| `fallback` | `ReactNode \| (error: Error) => ReactNode` | a short message | Shown over the frame after a load error. |
| `ref` | `Ref<HTMLIFrameElement>` | — | The iframe element. |
| `children` | `ReactNode` | — | Overlay content rendered over the frame. |
| `className` | `string` | — | Classes for the outer container; they override the defaults. |

Welcome to the **Marrow Component Registry**.

This registry provides a foundation for custom, copy-pasteable network engineering UI components built on the **shadcn registry specification**.

## Architecture

Components authored in `registry/` are packaged and distributed through:

1. **shadcn CLI**: `npx shadcn add <item>` directly from GitHub or our hosted registry.
2. **Native Marrow CLI**: `marrow add <item>`.
3. **Workspace Package**: `@marrow/ui` for internal consumption.

Ready to build components one by one.

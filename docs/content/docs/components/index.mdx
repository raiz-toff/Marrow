Welcome to **Marrow UI** (`@marrow/ui`). Every component in the Marrow topology ecosystem is authored in **React / Next.js TSX** and distributed through our **shadcn-compatible registry** (`registry.json`).

Just like shadcn/ui, you can copy and paste these components directly into your own applications or install them with a single CLI command.

---

## Component Catalog

Browse the individual components and blocks:

### 🛠️ Interactive Workbench
* **[Component Workbench](/docs/components/workbench)**: Zero-compiler testing studio to test, inspect, and evaluate every Marrow UI component in isolation and assembled.

### 🚀 Blocks
* **[Topology Shell](/docs/components/topology-shell)**: The complete, pre-assembled network studio with card-in-card grid, sidebar, canvas, inspector, and command search.

### 🧩 Workspace Components
* **[Topology Viewport](/docs/components/topology-canvas)**: Interactive stage viewport that mounts and frames compiled Marrow network diagrams with in-stage demo switching, theme sync, and camera HUD controls.
* **[Topology Inspector](/docs/components/topology-inspector)**: Floating 5-tab device telemetry drawer with interface tables, LLDP neighbors, and copyable CLI configurations.
* **[Topology Sidebar](/docs/components/topology-sidebar)**: Collapsible left navigation rail with security zone switcher, gliding hover indicator, and layer toggles.
* **[Topology Controls & Minimap](/docs/components/topology-controls)**: Floating vertical zoom/fit pill and interactive picture-in-picture minimap overlay.
* **[Command Search](/docs/components/topology-search)**: Keyboard-first `Ctrl+K` spotlight modal for searching devices, IPs, zones, and interfaces.

## Quickstart

Add any Marrow UI component to your Next.js or React application using the shadcn CLI:

```bash
# Add the complete studio block
npx shadcn@latest add https://marrow.run/r/topology-shell.json

# Or add just the inspector card
npx shadcn@latest add https://marrow.run/r/topology-inspector.json
```

Or install directly using the GitHub repository shorthand:

```bash
npx shadcn@latest add raiz-toff/Marrow/topology-shell
```

Marrow shares three focused React components through a **shadcn-compatible registry**. Like shadcn/ui, they are copied into your codebase as source — nothing is installed from npm under a Marrow name:

1. **[Marrow Diagram Embed](/docs/components/topology-canvas)**: Embed self-contained, interactive HTML network diagrams compiled with Marrow directly into Next.js or React applications with automatic dark/light theme syncing, fullscreen expansion, and minimal kiosk chrome.
2. **[Device Link & Micro-Topology](/docs/components/device-link)**: Compact, inline network link component for rendering peer-to-peer device interconnections without canvas or iframe overhead.
3. **[Cable & Link Badge](/docs/components/cable-badge)**: Visual cable mode (trunk, routed, tunnel, LAG) and line rate chips (1G–400G) with animated packet flow telemetry.

Each installs with one shadcn CLI command into your project's `components/marrow/` directory, together with `lucide-react`, `clsx` and `tailwind-merge`. They are styled with the standard shadcn theme tokens (`bg-card`, `border-border`, `text-muted-foreground`, …).

---

## Installation

Add a component to your Next.js or React application with the shadcn CLI:

### Marrow Diagram Embed
```bash
npx shadcn@latest add https://marrowdiagram.vercel.app/r/topology-canvas.json
```

### Cable & Link Badge
```bash
npx shadcn@latest add https://marrowdiagram.vercel.app/r/cable-badge.json
```

### Device Link
```bash
npx shadcn@latest add https://marrowdiagram.vercel.app/r/device-link.json
```

Inside a Marrow checkout, `npm run marrow -- add <name> --out <dir>` copies the same files.

## Usage Example

```tsx
import { MarrowEmbed } from "@/components/marrow/topology-canvas";
import { CableBadge } from "@/components/marrow/cable-badge";

export function NetworkDashboard() {
  return (
    <div className="flex flex-col gap-4 p-6">
      <div className="flex items-center gap-3">
        <CableBadge mode="trunk" speed="100G" status="up" animated />
        <CableBadge mode="routed" speed="25G" status="up" />
      </div>

      <MarrowEmbed src="/diagrams/campus.html" title="Campus core network" />
    </div>
  );
}
```

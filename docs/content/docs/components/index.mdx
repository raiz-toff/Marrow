Welcome to **Marrow UI** (`@marrow/ui`). Every component in the Marrow topology workspace is authored in **React / Next.js TSX** and distributed through our **shadcn-compatible registry** (`registry.json`).

## Spacious Shell Architecture

The `<TopologyShell />` replicates the **Fumadocs Spacious** layout grid for interactive network engineering diagrams:

1. **Recessed Outer Frame (`bg-fd-card`)**: The outer CSS grid (`grid-template: "sidebar main right" 1fr / var(--fd-sidebar-col) minmax(0, 1fr) auto`) acts as a quiet surface that frames the active workspace cards.
2. **Spacious Left Sidebar (`<TopologySidebar />`)**: Blends seamlessly into the outer frame with a `rounded-xl` security zone switcher dropdown, a `Ctrl+K` search pill, a smooth pointer-tracking gliding hover block, collapsible zone/device hierarchy, and canvas layer toggles.
3. **Floating Main Canvas Card (`<TopologyCanvas />`)**: A `rounded-2xl border bg-fd-background shadow-sm` stage card (`my-2 me-2`) housing a translucent floating top command bar, interactive pan/zoom SVG viewport, floating `<TopologyControls />`, and `<TopologyMinimap />`.
4. **Floating Sibling Inspector Card (`<TopologyInspector />`)**: A `w-[380px] my-2 me-2 rounded-2xl border bg-fd-background shadow-sm` sibling card with 5 segmented tabs (**Overview**, **Interfaces**, **Neighbors**, **Fields**, and **Config** with one-click CLI copy).
5. **Command & Search Spotlight (`<TopologySearch />`)**: Keyboard-first `Ctrl+K` modal for jumping to devices, IPs, security zones, links, or canvas actions.

## Installation via shadcn CLI

Install the complete Spacious Topology Shell or individual primitives into any Next.js / React project:

```bash
# Install the complete Spacious Topology Shell block
npx shadcn@latest add https://marrow.run/r/topology-shell.json

# Or install directly from the GitHub registry
npx shadcn@latest add raiz-toff/Marrow/topology-shell
```

## Usage in Next.js / React (TSX)

```tsx
import { TopologyShell, type TopologyData } from "@marrow/ui";

export default function NetworkDiagramPage() {
  return (
    <main className="p-4">
      <TopologyShell
        defaultSelectedDeviceId="core-sw-01"
        height="calc(100dvh - 2rem)"
      />
    </main>
  );
}
```

### Customizing Slots

Because `<TopologyShell />` is built on `<TopologyProvider />` and `useTopologyShell()`, you can compose or replace individual panels while keeping shared selection, hover neighborhood dimming, and camera state:

```tsx
import {
  TopologyShell,
  TopologySidebar,
  TopologyCanvas,
  TopologyInspector,
  TopologySearch,
} from "@marrow/ui";

export function CustomTopologyWorkspace({ data }) {
  return (
    <TopologyShell data={data} height="760px">
      <TopologySidebar />
      <TopologyCanvas />
      <TopologyInspector />
      <TopologySearch />
    </TopologyShell>
  );
}
```

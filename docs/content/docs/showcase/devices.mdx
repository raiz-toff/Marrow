import { DeviceFrame, ResizableFrame } from '@/components/showcase/frames';

The diagram picks its layout from the width of its own viewport. Inside an iframe that is the
iframe's width, not the reader's screen. Each frame below is an iframe of exactly the device's
CSS viewport, drawn inside a bezel; on a narrow screen the whole device scales down instead of
overflowing.

- **Below 768 px (phone):** the command bar and the minimap are hidden, a bottom bar holds the
  brand, the page selector, search, the sidebar and the theme switch, the sidebar is a drawer,
  and the inspector opens as a bottom sheet. Drag its handle to snap it between peek, half and full.
- **768 to 1024 px (tablet):** the sidebar becomes a drawer over the page and starts closed; the
  inspector stays beside the diagram.
- **Touch:** controls are at least 44 × 44 px on phones and wherever the pointer is coarse.

Every frame on this page loads the same file, `zoned.html`, built from `docs/demos/zoned.yaml`
(<Devices demo="zoned.yaml" /> devices in two zones). Only the URL changes.

Flags go in the query (`?chrome=minimal`) or in the hash (`#chrome=minimal;inspector=off`).
When both name the same flag, the query wins. Separate hash pairs with `;`. The examples
here use the hash, so your browser fetches the file once for all of them.

## Theme

Without a flag the YAML decides: `zoned.yaml` declares `theme: dark`, so this file is dark
whatever your site's theme is. A YAML with `theme: auto` follows the reader's system setting.
`theme=` overrides both. The [React component](/docs/showcase/embedding#react-component) sets it
for you from your site's theme.

## Flags stay put

The diagram rewrites only its own `d` and `c` pairs and keeps every other pair as you wrote it,
so panning and clicking never drop your flags. On a multi-page Site, links between pages carry
the active flags, so a reader who navigates stays in the mode you embedded. Try it below: click a
zone on the overview, and the zone page opens still minimal and light.

<Specimen title="Flags across Site pages" url="/demo/scale-site/index.html#chrome=minimal;theme=light">
  The overview of the 625-device Site from [Single file or Site](/docs/showcase/output). Each page it links to opens with `chrome=minimal;theme=light`.
</Specimen>

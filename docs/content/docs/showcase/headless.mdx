## marrow snapshot

`snapshot` compiles the YAML and photographs it in headless Chromium, at the size you ask for
(1440 × 900 unless you say otherwise). Agents use it to look at a diagram before you do; it
is also the quickest way to get a picture into a ticket or a chat. `--focus` selects a device
first, and `--theme` overrides the YAML's theme.

## Print

Printing uses the light palette on white paper, whatever the screen theme. The interface
(sidebar, command bar, minimap, controls, inspector) is hidden, every device name and port label
prints regardless of the zoom on screen, and animation stops. On SVG pages the whole diagram is
fitted to the page rather than the part the camera shows. This is `zoned.html`, a dark diagram, as Chromium lays
it out for an A4 page.

## Export menu

Every diagram can save itself: open the sidebar's **Export** menu, the command center
(<kbd>Ctrl</kbd> <kbd>K</kbd>, or <kbd>⌘</kbd> <kbd>K</kbd> on a Mac) or the right-click menu.
**Export PNG** works on every page; **Export SVG**, a standalone vector file, appears on pages
drawn as SVG. **Print…** is in the same menu.

## marrow serve

`npm run dev` runs `marrow serve`: a preview on 127.0.0.1 (port 5200 by default) that rebuilds
when you save a YAML file and reloads the open page over server-sent events. Here, the file
gained a device and `dc-srv-02` was marked `status: down`; the page reloaded on its own. A save
that does not validate shows the diagnostics in a banner and leaves the last good diagram up.

Every diagram below was produced by `marrow build` from a few lines of YAML —
no coordinates, no hand-placement. Click a card to open the real, interactive
file in a viewer: drag to pan, scroll to zoom, click a device for its inspector.
Nothing here is a screenshot, and nothing is fetched from a server.

::marrow-showcase
::

Want the source? Each diagram is one file under
[`docs/demos/`](https://github.com/raiz-toff/Marrow/tree/main/docs/demos) — copy it,
change a line, and run `npm run build` to make it your own. New to the format?
Start with [authoring](/docs/guides/authoring) and the [schema reference](/docs/reference/schema).
